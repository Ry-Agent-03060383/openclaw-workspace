# 焦作市智慧金融服务平台 — 系统使用手册

> 版本 1.0.0 | 更新日期 2026-06-17

---

## 一、系统概述

焦作市智慧金融服务平台是一个面向中小微企业、农户、金融机构和政府部门的综合性金融服务平台，提供贷款申请、征信查询、风险评估、贷后监控等全流程金融服务。

### 技术架构

| 层级 | 技术栈 |
|------|--------|
| 前端 | Vue 3 + TypeScript + Element Plus + Vite |
| 后端 | Spring Boot 3.2 + Spring Security + JPA |
| 数据库 | H2（开发）/ MySQL（生产） |
| 部署 | 单 JAR 包（前后端一体） |

### 访问地址

| 环境 | 地址 |
|------|------|
| 首页 | `http://localhost:8080/` |
| 登录 | `http://localhost:8080/login` |
| 管理后台 | `http://localhost:8080/dashboard` |

---

## 二、角色说明

平台支持 7 种用户角色，不同角色拥有不同的功能权限：

| 角色 | 标识 | 功能范围 |
|------|------|----------|
| 平台管理员 | ADMIN | 全部功能：用户管理、贷款管理、征信评级、风险处置、贷后监控、AI客服 |
| 中小企业 | SME | 贷款申请、征信评级、AI客服 |
| 金融机构 | FINANCIAL_INSTITUTION | 贷款审核、企业征信、贷后监控 |
| 农户 | FARMER | 贷款申请、政策咨询（AI客服） |
| 政府部门 | GOVERNMENT | 贷款数据查看、区域监控 |
| 风控人员 | RISK_MANAGER | 贷款审核、风险处置 |
| 第三方服务商 | THIRD_PARTY | 服务订单、客服 |

## 三、快速开始

### 3.1 登录系统

1. 在浏览器中打开 `http://localhost:8080/login`
2. 首页展示焦作市智慧金融服务平台的品牌形象页，点击导航栏"登录"按钮或直接访问 `/login`
3. 在登录页选择对应的角色卡片（共 7 种角色）
4. 输入用户名和密码，点击"登录"
5. 登录成功后自动跳转至该角色的操控台首页

## 四、模块操作指南

### 4.1 操控台（首页）

每个角色登录后看到不同的操控台页面，展示与角色相关的统计数据：

| 角色 | 展示数据 |
|------|----------|
| ADMIN | 用户数、企业数、农户数、贷款申请数、信用报告数、风险评估数 |
| SME | 我的贷款数、信用评分、可用产品数 |
| BANK | 待审核贷款、已放款贷款、风险预警数 |
| FARMER | 我的贷款数、信用评分 |
| GOVERNMENT | 总贷款额、企业数、农户数、区域覆盖数 |
| RISK_MANAGER | 待评估数、高风险数、已完成评估数 |
| THIRD_PARTY | 服务订单数、服务收入、客户数 |

### 4.2 贷款管理

#### 中小企业申请贷款

1. 以 SME 角色登录（enterprise1 / 123456）
2. 左侧菜单选择"贷款申请"
3. 点击"申请贷款"按钮
4. 在弹出的表单中填写：
   - **贷款产品**：选择贷款产品（企业经营贷款/科技企业专项贷/个人经营贷款/农户专项贷款/农业产业链贷款）
   - **企业名称**：输入企业全称
   - **信用代码**：输入统一社会信用代码
   - **贷款金额**：设置金额（≥10000）
   - **贷款期限**：选择期限（6/12/24/36个月）
   - **还款方式**：选择方式（等额本息/等额本金/先息后本）
   - **贷款用途**：填写具体用途说明
5. 点击"提交申请"
6. 申请提交成功后，状态显示为"已提交"

#### 金融机构审核贷款

1. 以 BANK 角色登录（bank1 / 123456）
2. 左侧菜单选择"贷款审核"
3. 查看待审核贷款列表
4. 对每笔贷款可进行以下操作：
   - **通过**：点击绿色"通过"按钮，贷款状态变为"已通过"
   - **驳回**：点击红色"驳回"按钮，输入驳回原因，贷款状态变为"已驳回"

#### 管理员查看全部贷款

1. 以 ADMIN 角色登录（admin / 123456）
2. 左侧菜单选择"贷款管理"
3. 查看所有角色的贷款申请列表，包括全部状态

### 4.3 征信评级

企业信用评分与报告管理，适用于 SME、BANK、ADMIN 角色。

1. 左侧菜单选择"征信评级"
2. **搜索企业**：
   - 企业用户：自动加载本企业信息
   - 银行/管理员：可按企业名称或统一信用代码搜索
3. 点击企业卡片选择目标企业
4. **查看信用评分**：
   - 环形进度条显示综合信用评分（0-100）
   - 信用等级标签（AAA/AA/A/BBB/BB/B/C）
   - 风险等级标签（低风险/中等风险/高风险）
   - 四维度评分分析：基本信息(30%)、信用历史(35%)、财务状况(25%)、行业环境(10%)
5. **重新评估**：点击"重新评估"按钮，系统自动重新计算信用评分
6. **信用报告管理**：
   - 点击"生成报告"按钮生成正式信用报告
   - 报告列表中查看已生成的报告
   - 点击查看图标查看报告详情（包含风险分析、财务信息、行业信息、建议）

### 4.4 风险处置

风险评估管理，适用于 ADMIN、RISK_MANAGER 角色。

1. 左侧菜单选择"风险处置"
2. **查看评估列表**：表格展示所有风险评估记录
   - 展开行可查看四维度评分（基础资质/信用记录/财务状况/行业风险）
   - 查看评估建议文本
3. **发起评估**：
   - 点击"发起评估"按钮，选择评估类型
   - **企业风险评估**：对指定企业进行综合风险评分
   - **贷款申请风险评估**：对指定贷款申请进行风险评分
4. **查看风险报告**：点击查看图标打开详细报告弹窗
   - 维度评分 Tab：四维度评分详情与权重
   - 详细信息 Tab：成立年限、注册资本、经营状态、行业等
   - 评估建议 Tab：系统生成的风险处置建议
   - 原始报告 Tab：完整的 JSON 格式风险报告

### 4.5 贷后监控

贷款跟踪与风险预警，适用于 ADMIN、BANK、GOVERNMENT 角色。

1. 左侧菜单选择"贷后监控"
2. **统计概览**：顶部卡片展示贷款总笔数、已通过、待审核、已拒绝、高风险评估数
3. **贷款跟踪表**：左侧表格展示全部贷款的编号、企业、金额、期限、状态、备注
4. **风险预警**：右侧面板显示最近的风险评估记录，按等级和评分排序
5. **监控概览**：显示已贷出总额、评估覆盖率、通过率等统计

### 4.6 AI智能客服

智能问答与政策咨询，适用于所有角色。

1. 左侧菜单选择"AI客服"（农户显示为"政策咨询"，银行显示为"客服"）
2. **快捷提问**：点击页面顶部的快捷问题按钮（贷款申请流程、征信查询、利率说明等）
3. **自由提问**：在底部输入框输入问题，按 Enter 发送
4. **角色感知回答**：系统根据用户角色自动调整回答内容
   - SME：侧重企业贷款流程、科技补贴政策
   - FARMER：侧重惠农贷款政策、农户贷款材料
   - BANK：侧重审核流程
5. 支持的问题类型：
   - 贷款流程相关问题
   - 征信查询相关问题
   - 利率和费用相关问题
   - 申请材料相关问题
   - 还款方式相关问题
   - 贷款期限相关问题
   - 惠农政策相关问题
   - 科技补贴相关问题
   - 服务商入驻相关问题

### 4.7 用户管理

仅 ADMIN 角色可用。

1. 左侧菜单选择"用户管理"
2. **搜索用户**：按用户名、姓名、手机号搜索
3. **用户列表**：表格展示用户名、姓名、角色、手机号、状态、创建时间
4. **创建用户**：点击"创建用户"按钮填写信息
5. **编辑用户**：点击编辑图标修改用户信息
6. **状态切换**：点击"启用/禁用"按钮切换用户状态
7. **删除用户**：点击删除图标确认删除

## 六、常见问题

### 6.1 登录后页面空白
- 确认已正确选择角色（登录页有 7 个角色卡片）
- 清除浏览器缓存后重试

### 6.2 贷款申请提交失败
- 确认所有必填字段已填写完整
- 贷款产品必须选择
- 贷款金额必须 ≥ 10000

### 6.3 征信报告数据为空
- 先选择目标企业
- 点击"生成报告"按钮生成新的报告
- 报告有效期 3 个月

### 6.4 风险等级显示异常
- 企业基本信息（注册资本、成立日期等）不全会影响评分
- 点击"重新评估"按钮触发系统重新计算
